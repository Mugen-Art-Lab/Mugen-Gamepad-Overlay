# Установщик Windows

Установщик собирается через Inno Setup 6 после успешной сборки DLL.

Обычный путь:

1. Запустить `BUILD_WINDOWS.cmd` в корне репозитория.
2. Скрипт создаст рабочую папку при необходимости и соберёт конфигурацию `Release`.
3. `tools/package-release.ps1` подготовит стандартный и portable ZIP.
4. Если Inno Setup найден, автоматически появится `Mugen-Gamepad-Overlay-0.8.0-Windows-x64-Setup.exe`.

Если Inno Setup ещё не установлен:

```powershell
winget install JRSoftware.InnoSetup
```

После установки снова запустите `BUILD_WINDOWS.cmd`: скрипт заново подготовит временный payload и соберёт Setup.exe.

Установщик предназначен для обычной OBS и ставит плагин в `C:\ProgramData\obs-studio\plugins\mugen-gamepad-overlay`. Для portable или нестандартной OBS используется отдельный portable ZIP.

## Поведение установщика

- Отдельной страницы принятия GPL нет: лицензия не требует согласия для обычного использования. Полный текст GPL-2.0-or-later устанавливается вместе с плагином.
- Если OBS Studio запущена, установщик показывает окно с кнопками «Повторить» и «Отмена». После закрытия OBS достаточно нажать «Повторить» — перезапускать установщик не нужно.
- Деинсталлятор использует такую же повторную проверку OBS.

## Локализация

- Первое окно выбора языка имеет двуязычный заголовок и пояснение, так как оно показывается до выбора языка.
- После выбора языка информационная страница полностью соответствует выбранному языку.
- Проверка запущенной OBS использует собственные локализованные кнопки `Retry / Cancel` или `Повторить / Отмена`, независимо от языка Windows.
