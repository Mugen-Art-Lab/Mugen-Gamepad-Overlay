# Support

Please report reproducible bugs at:

https://github.com/Mugen-Art-Lab/Mugen-Gamepad-Overlay/issues

Include:

- OBS Studio version and architecture;
- Windows version;
- plugin version and installation method;
- controller name, connection mode, and any virtual-controller software;
- selected skin source and file, when relevant;
- exact steps to reproduce;
- screenshots and the current OBS log.

General controller-driver, Bluetooth, Steam Input, DS4Windows, and third-party skin authoring problems may be outside the plugin itself, but a clear report can still help document compatibility.
