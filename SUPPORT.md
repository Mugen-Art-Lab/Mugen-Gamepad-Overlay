# Support and feedback

For questions, ideas and general feedback, visit the official **Mugen Art Lab** website:

https://mugenartlab.com/

Choose **Write** to send a message. This is optional: the plugin works entirely locally and does not contact the site.

For reproducible technical bugs, you can also open a GitHub Issue:

https://github.com/Mugen-Art-Lab/Mugen-Gamepad-Overlay/issues

Please include:

- OBS Studio version (for example, 32.2.x or 33.0.x) and x64 architecture;
- Windows version and whether HDR is enabled, when relevant;
- Mugen Gamepad Overlay version and installation method (installer / standard ZIP / portable ZIP);
- controller name, connection mode, and any virtual-controller software;
- selected skin source and file, plus whether **Use one source size for all skins** is enabled;
- precise steps to reproduce and expected vs actual result;
- relevant screenshots, a native **Screenshot (Source)** when visual output differs, and the current OBS log.

If the plugin is missing in OBS 33, mention whether the Plugin Manager marks it **Legacy**. See [INSTALL.md](INSTALL.md) for how to collect the current log and verify installation paths.

General controller drivers, Bluetooth, Steam Input, DS4Windows and third-party skin authoring may be outside the plugin itself, but well-described issues still help document compatibility.
