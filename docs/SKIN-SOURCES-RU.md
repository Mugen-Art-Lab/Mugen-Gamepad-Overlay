# Источники скинов

Сторонние скины не входят в Mugen Gamepad Overlay.

## Полностью проверено

### frolovlife/gamepadviewer-skins

https://github.com/frolovlife/gamepadviewer-skins

Большая ретроколлекция GamepadViewer CSS: Nintendo, Sega, NEC, SNK, Sony, 3DO, 8BitDo и другие контроллеры. Вся коллекция вручную проверена с Mugen Gamepad Overlay 0.6.3–0.8.0.

Скачивать нужно весь репозиторий через `Code → Download ZIP`, сохраняя структуру папок. В свойствах источника выбирается конкретный `.css`.

## Проверено

### Input Overlay 5.0.5 presets

Игровые JSON+PNG-пресеты из официального набора Input Overlay 5.0.5. Клавиатурные и мышиные пресеты для Mugen Gamepad Overlay не нужны.

Выбирается JSON, после чего плагин ищет PNG рядом и предлагает варианты оформления.

## Важно

Совместимость с произвольным CSS из интернета не гарантируется. GamepadViewer допускает очень свободную браузерную разметку, а Mugen Gamepad Overlay намеренно реализует только безопасное локальное подмножество без браузера и JavaScript.
