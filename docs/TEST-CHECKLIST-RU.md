# Чек-лист Mugen Gamepad Overlay 0.8.0

Проверять старые технические CSS-стенды и Mugen JSON больше не нужно.

## 1. Сборка и установка

1. Полностью закройте OBS и убедитесь, что `obs64.exe` исчез из Диспетчера задач.
2. Запустите `PATCH_EXISTING_PROJECT_AND_BUILD.cmd`.
3. Выберите прежнюю рабочую папку `Mugen-Gamepad-Overlay` с `build_x64`.
4. Установите полученный ZIP поверх предыдущей тестовой версии.
5. Запустите OBS и откройте существующий источник.

Ожидаемый архив сборки:

`Mugen-Gamepad-Overlay-0.8.0-windows-x64-RelWithDebInfo.zip`


## 2. Живое обновление списка геймпадов

1. Открой свойства источника с подключённым геймпадом.
2. В первой строке списка должно быть `Автоматически (сейчас: ИМЯ [ID])`.
3. Не закрывая свойства, отключи текущий геймпад и подключи другой.
4. В течение примерно секунды должны обновиться:
   - имя внутри автоматического пункта;
   - отдельные устройства в списке;
   - автоматические обозначения лицевых кнопок;
   - подписи и варианты первых четырёх строк расширенного переназначения.
5. Отключи все поддерживаемые геймпады: автоматический пункт должен сообщить, что геймпад не подключён.
6. Подключи геймпад снова: имя и подписи должны вернуться без закрытия окна.

## 3. Обозначения лицевых кнопок и универсальный технический скин

### Автоматический режим

1. Оставьте «Обозначения лицевых кнопок» в режиме «Автоматически по данным устройства».
2. С DualSense в универсальном скине должны отображаться `✕ / ○ / □ / △`.
3. Раскройте «Расширенную настройку ввода»: названия четырёх строк и первые четыре SDL-варианта в каждом списке должны использовать те же символы.
4. С Flydigi Vader / Xbox-подобным контроллером должны отображаться `A / B / X / Y`.

### Ручное переключение

Последовательно выберите Xbox, PlayStation и Nintendo. Для каждой схемы проверьте одновременно:

- встроенный универсальный скин;
- подписи четырёх лицевых действий;
- первые четыре SDL-пункта в раскрывающихся списках переназначения.

Ожидаемые раскладки: Xbox `A / B / X / Y`, PlayStation `✕ / ○ / □ / △`, Nintendo `B / A / Y / X`. После проверки верните автоматический режим.

Импортированные Input Overlay и GamepadViewer-скины менять свои нарисованные подписи не должны.

### DualSense

- Четыре лицевые кнопки реагируют.
- Крестовина работает во всех направлениях.
- Оба стика двигаются, L3/R3 нажимаются.
- L2/R2 заполняются плавно.
- В автоматическом режиме видны Share/Back, Options/Start, PS/Guide, Touchpad и кнопка микрофона/Misc.
- Нажатие каждого доступного служебного элемента подсвечивается.

### Flydigi Vader / Xbox-подобный контроллер

- Основные кнопки, крестовина, стики, L3/R3 и триггеры работают.
- В автоматическом режиме отображается Guide/Home.
- Возможности DualSense не должны появляться без режима «Показывать все».

## 4. Переназначение триггеров

### Кнопка как логический триггер

1. Откройте «Расширенную настройку ввода».
2. Убедитесь, что обе строки триггеров стоят в автоматическом режиме и штатные L2/R2 по-прежнему двигаются плавно.
3. Для `Левый триггер / LT / L2` выберите физическую кнопку Y.
4. Нажатие Y должно давать левому триггеру ровно `100%`, отпускание — `0%`.
5. Проверьте результат во встроенном скине и хотя бы в одном импортированном скине, который показывает L2.
6. Верните левый триггер в автоматический режим.

### Аналоговый триггер как логическая кнопка

1. Для любой логической кнопки, например Y, выберите `Левый триггер / LT / L2 — как кнопка`.
2. Медленно нажимайте LT/L2: кнопка должна включаться только после значения из `Порог триггера как кнопки`.
3. Измените порог и убедитесь, что точка срабатывания изменилась.
4. Проверьте правый триггер аналогичным способом.
5. Верните переназначенные кнопки к исходным источникам.

### Необычные источники

- При наличии подходящего контроллера выберите Raw button как источник триггера: ожидается цифровое `0% / 100%`.
- Для Raw axis проверьте полный диапазон и подходящее направление. Полный диапазон переводит исходные `-100…+100%` в логические `0…100%`; для оси с нейтралью в центре обычно удобнее положительное или отрицательное направление.
- Убедитесь, что назначения не образуют цепочек: каждая строка должна реагировать только на исходный физический сигнал.

## 5. Input Overlay: статус и варианты

1. Откройте `qa-tests/input-overlay-variants/demo-pad.json`.
2. Должно быть найдено 3 PNG-варианта.
3. Строка статуса должна говорить про Input Overlay, а не про CSS.
4. Выберите `demo-pad.png`, `demo-pad-light.png` и `demo-pad-purple.png`.
5. Корпус должен стать соответственно тёмным, светлым и фиолетовым.
6. Проверьте A/B/X/Y, крестовину, Back/Start и L/R.
7. Затем проверьте один-два настоящих пресета из Input Overlay 5.0.5.

## 6. GamepadViewer

Используйте настоящие скины из `frolovlife/gamepadviewer-skins`, а не внутренний демо-скин.

Минимальный прогон:

- один ретроконтроллер без стиков;
- DualShock / DualShock 2 — оба стика и L3/R3;
- 8BitDo Pro 2/3 — оба стика и отражённые слои;
- Neo Geo / Sega — направления и режим «левый стик вместо крестовины».

После перехода с Input Overlay строка статуса должна снова говорить именно про GamepadViewer CSS.

## 7. Ожидаемая ошибка

1. Выберите `qa-tests/expected-error/missing-texture.json` в режиме Input Overlay.
2. Должен появиться экран `SKIN NOT LOADED`.
3. В свойствах должна быть причина ошибки.
4. Встроенный универсальный пад не должен молча подменять ошибочный пресет.

## 8. Стабильность

- Закройте свойства и откройте снова.
- Перезапустите OBS.
- Отключите и снова подключите геймпад.
- По возможности смените USB-порт.
- Проверьте хоткей включения/выключения источника.
- Переведите Windows в гибернацию и вернитесь.
- После обычной работы проверьте журнал OBS на повторяющиеся ошибки и чрезмерный рост.
