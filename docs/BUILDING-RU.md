# Сборка под Windows

[English version](BUILDING.md)

## Требования

- Windows 10 или Windows 11 x64;
- Visual Studio 2022 либо Build Tools 2022 с компонентом **Разработка классических приложений на C++**;
- инструменты MSVC x64/x86, Windows SDK и CMake tools for Windows;
- интернет для первого создания рабочей папки;
- необязательно: Inno Setup 6 для сборки установщика.

В репозитории хранится часть проекта, относящаяся непосредственно к плагину, а не полная копия инфраструктуры OBS. Скрипт создаёт `build-workspace/` из зафиксированной ревизии `7540ffa` официального [`obsproject/obs-plugintemplate`](https://github.com/obsproject/obs-plugintemplate). Эта папка игнорируется Git, не является вторым репозиторием и может быть целиком удалена для чистой пересборки. Служебные GitHub-workflow шаблона, демонстрационные файлы и публичные QA-пресеты туда не копируются. Назначение папки описано в `GENERATED-WORKSPACE.txt`.

## Сборка одной командой

Полностью закройте OBS Studio и запустите:

```text
BUILD_WINDOWS.cmd
```

При первом запуске скрипт:

1. скачает зафиксированную ревизию шаблона OBS;
2. создаст `build-workspace/`;
3. перенесёт туда исходники и документацию Mugen Gamepad Overlay;
4. через CMake скачает зафиксированные версии SDL3 и NanoSVG;
5. соберёт конфигурацию Windows x64 `Release`;
6. подготовит релизные файлы.

Следующие сборки используют ту же рабочую папку и уже скачанные зависимости.

## Результат

Публичные релизные файлы создаются в:

```text
build-workspace\release\0.8.0
```

Ожидаемый набор:

```text
Mugen-Gamepad-Overlay-0.8.0-Windows-x64-Setup.exe
Mugen-Gamepad-Overlay-0.8.0-Windows-x64.zip
Mugen-Gamepad-Overlay-0.8.0-Windows-x64-portable.zip
SHA256SUMS.txt
```

Если Inno Setup 6 не установлен, установщик не создаётся, но ZIP-архивы будут готовы. Установить Inno Setup можно командой:

```powershell
winget install JRSoftware.InnoSetup
```

После установки снова запустите `BUILD_WINDOWS.cmd`.

## Полностью чистая рабочая папка

Чтобы заново получить шаблон OBS и все сборочные кэши, удалите `build-workspace/` и снова запустите `BUILD_WINDOWS.cmd`. Для обычного изменения исходников удалять её не нужно: инкрементальная сборка намного быстрее.

## Важно

- рабочая папка и результаты сборки не попадают в Git;
- релизная DLL собирается из исходников этого репозитория и зафиксированных зависимостей из `CMakeLists.txt`;
- перед установкой, заменой или удалением DLL полностью закрывайте OBS Studio.
