# Первый тест 0.8.0

1. Полностью закройте OBS.
2. Соберите релиз через `BUILD_WINDOWS.cmd`.
3. Установите полученный Setup.exe либо стандартный ZIP.
4. Проверьте автоматические обозначения: DualSense должен показать `✕ / ○ / □ / △`, а Vader/Xbox-подобный контроллер — `A / B / X / Y`.
5. Переключите вручную Xbox, PlayStation и Nintendo и проверьте встроенный скин и списки расширенного переназначения.
6. В расширенной настройке назначьте Y источником левого триггера: нажатие Y должно давать L2 значение 100%.
7. Назначьте `Левый триггер — как кнопка` логической Y и проверьте регулируемый порог срабатывания, затем верните настройки по умолчанию.
8. Откройте `qa-tests/input-overlay-variants/demo-pad.json`, переключите три PNG-варианта и убедитесь, что статус говорит про Input Overlay, а не про CSS.
9. Откройте несколько настоящих CSS-скинов из `frolovlife/gamepadviewer-skins`.
10. Откройте `qa-tests/expected-error/missing-texture.json`: должен появиться экран `SKIN NOT LOADED`.
11. Перезапустите OBS и проверьте сохранение настроек.
12. Полный план находится в `docs/TEST-CHECKLIST-RU.md`.
