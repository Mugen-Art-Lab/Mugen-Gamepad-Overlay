# QA-тесты 0.8.0

Эта папка содержит только два понятных проверочных сценария и не устанавливается вместе с плагином.

- `input-overlay-variants` — рабочий тест трёх PNG-вариантов одного JSON.
- `expected-error` — намеренно неполный пресет для проверки экрана ошибки.

Старые технические GamepadViewer-стенды и скрытые Mugen JSON-примеры удалены из архива:
они путали ручную проверку и не давали ничего полезнее реальных скинов `frolovlife`.

GamepadViewer проверяйте на настоящей коллекции `frolovlife/gamepadviewer-skins`.
