Ожидаемая ошибка загрузки для Mugen Gamepad Overlay 0.8.0.

1. Источник скина: «Пресет Input Overlay 5.x (JSON + PNG)».
2. Выберите missing-texture.json.
3. Рядом намеренно нет PNG-файла.
4. В предпросмотре должен появиться экран SKIN NOT LOADED.
5. В строке статуса должна быть причина ошибки Input Overlay.
6. Встроенный универсальный геймпад не должен появляться вместо ошибки.

Этот файл намеренно неполный. Он нужен только для проверки обработки ошибок.
