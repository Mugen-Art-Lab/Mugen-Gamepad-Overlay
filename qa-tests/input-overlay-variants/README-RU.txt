Тест переключения PNG-вариантов Input Overlay для Mugen Gamepad Overlay 0.8.0.

Это не комплектный пользовательский скин, а небольшой проверочный атлас.

Как проверить:
1. Источник скина: «Пресет Input Overlay 5.x (JSON + PNG)».
2. Выберите demo-pad.json.
3. Должно быть найдено 3 PNG-варианта.
4. Раскройте «Вариант оформления» и по очереди выберите:
   - demo-pad.png — тёмный корпус;
   - demo-pad-light.png — светлый корпус;
   - demo-pad-purple.png — фиолетовый корпус.
5. Строка статуса не должна упоминать CSS или GamepadViewer.
6. Проверьте A/B/X/Y, крестовину, Back/Start и L/R.

Режим «Автоматически» специально выбирает demo-pad.png, поэтому два скриншота
с одним и тем же автоматическим вариантом будут выглядеть одинаково.
