# Contributing

Bug reports and narrowly scoped fixes are welcome. Please open an issue before starting a large feature or compatibility change.

Contributions must:

- remain compatible with GPL-2.0-or-later;
- avoid bundling third-party skins without explicit redistribution permission;
- preserve local-only operation unless a network feature is explicitly discussed and approved;
- include clear reproduction steps and real OBS testing;
- disclose substantial use of AI tools in the pull request.

The 0.8.x line is intentionally focused on normalized SDL Gamepad input. Raw Joystick/HOTAS support is a separate future design problem rather than a small mapping patch.
